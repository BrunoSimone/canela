# INV-100 — stock autoritativo en Sanity

2026-10-17. Spec 100 / ADR-006.

## Verificación

- 434 pruebas unitarias/HTTP pasan; 59 pruebas de integración con PostgreSQL 17
  desechable pasan. Las pruebas SQL ejecutan el adaptador real de inventario con
  un doble del almacén de documentos, sin servicios de pago/envío reales.
- Contrato contra Sanity `inventory_test`: dos solicitudes concurrentes para una
  unidad dan un solo ganador; consumir dos veces deja saldo cero; acceso anónimo
  al documento privado no devuelve cantidades. Fixtures del contrato eliminados.
- TypeScript, ESLint, build Next y validación del esquema Studio sin errores.
- UI local con sesión real Sanity: abrir Producto → Stock, cambiar 1 → 0 → 1,
  leer historial y verificar actor/motivo. Las cantidades de QA están en
  `inventory_test`, separadas del catálogo y del stock productivo.
- Recuperación probada: timeout después de reservar; retry sin segunda reserva;
  intención abandonada cancelada con marca terminal; expiración no libera una
  reserva lista para MP; fallo SQL después de consumo converge al reintentar sin
  descuento duplicado ni aviso fantasma.

## Corte de producción

Respaldo Neon `pre-sanity-stock-20261017`, rama `br-lucky-mud-ac5ovpvz`.
Comprobación previa: cero pedidos, cero filas de stock anterior, cero reservas
activas. Migración 0013 aplicada; no hubo cantidades reales que copiar.
Token de backend y dataset `production` configurados en Vercel; local usa
`inventory_test`. Los documentos usan rutas privadas con punto, según el contrato
de acceso de Sanity. Las tablas antiguas se conservan como historial de migración,
sin lectores, escritores ni fallback de saldos en la aplicación.

El cliente debe cargar sus cantidades reales desde Studio. La tienda conserva
mantenimiento y checkout deshabilitado. La aceptación de una compra externa
MP → Zipnova → Resend sigue pendiente de los datos y habilitaciones comerciales.

## Comprobación del despliegue

- Vercel Production y Studio publicados. Sesión real de administrador en el
  Studio alojado: Producto → Stock carga las cantidades de producción, con
  guardado e historial disponibles. No se introdujo stock ficticio en producción.
- `/` y `/checkout` conservan HTTP 503 de mantenimiento; `/admin/inventario`
  redirige a Sanity. La API de stock responde 401 sin identidad; el preflight CORS
  permite el origen exacto del Studio.
- Worker de producción completado correctamente tras el corte:
  https://github.com/BrunoSimone/canela/actions/runs/39045959106.

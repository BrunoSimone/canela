## Corrección de credenciales

La validación anterior suponía que un token de prueba debía comenzar con
`TEST-`. La documentación oficial actual de Checkout Pro/Orders confirma que el
token de prueba también puede comenzar con `APP_USR`, igual que el productivo.

La separación ahora se expresa mediante `MP_TEST_ACCESS_TOKEN`. El modo
productivo continúa sin existir hasta integrar una cotización real de Correo.
No se infiere el ambiente inspeccionando el secreto.

Fuentes:

- [Credenciales de Checkout API Orders](https://www.mercadopago.com.ar/developers/es/docs/checkout-api-orders/resources/credentials)
- [Cuentas de prueba de Checkout Pro](https://www.mercadopago.com.ar/developers/es/docs/checkout-pro-preferences/test-accounts)

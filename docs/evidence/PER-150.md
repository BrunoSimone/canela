# PER-150 — Checkout en dos pasos

Fecha: 2026-10-28. Rama: `codex/creador-cuadros-personalizados`.

## Implementado

- El primer paso muestra contacto y domicilio. «Continuar» se habilita con datos
  válidos y consulta las tarifas antes de presentar el resumen.
- El segundo paso muestra destino, opciones de envío vigentes, piezas, total y
  «Continuar a Mercado Pago». Avanzar al resumen no inicia el pago.
- Se preselecciona la tarifa vigente más económica. Cambiarla actualiza el total.
- Editar conserva los campos y exige una nueva confirmación. Cambios del carrito,
  errores de tarifa y vencimientos impiden pagar con un resumen desactualizado.
- Solicitudes duplicadas y resultados tardíos de otro carrito están cubiertos.
- El formulario de envío de cuadros utiliza también «Continuar».
